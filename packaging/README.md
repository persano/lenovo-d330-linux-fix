# Native Packaging for Lenovo IdeaPad D330-10IGL

Contains packaging manifests for Debian/Ubuntu, Fedora/openSUSE, and Arch Linux.

## Directory Structure
- `debian/`: Debian package metadata (`control`, `rules`, `changelog`, `postinst`).
- `rpm/lenovo-d330-fix.spec`: RPM spec file.
- `arch/PKGBUILD`: Arch Linux PKGBUILD recipe.
