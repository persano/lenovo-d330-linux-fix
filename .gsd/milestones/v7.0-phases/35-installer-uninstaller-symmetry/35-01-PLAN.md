# Phase 35 Plan 35-01: Installer & Uninstaller Symmetry

## Objective

Make `--install` and `--uninstall` exact inverses (audit M1/M2/M11/N6): a single deploy manifest drives install, uninstall and a new `--verify` mode; GRUB is regenerated on both paths; `--uninstall` works in a rescue shell; every shipped unit (9) is enabled at all three enable sites; foreign systemd drop-ins are safe from broad `rm`s; uninstall closes its gaps; silent skips warn by name. Symmetry becomes machine-checked, not eyeballed.

## Research Corrections (auditor-visible)

1. **Shipped unit count is 9, not 8** (35-RESEARCH): `lenovo-d330-camera-loopback.service` still ships after phase 34's resume-service deletion; current enables are install_dkms 8, deb 7, rpm %post 4. Roadmap SC2 "all 9" holds once camera-loopback is enabled. Context corrected accordingly.
2. **10 asymmetric rows** in the install/uninstall inventory (6 NOT REVERSED — M1 generic grub.d regen, M2 camera-loopback, N6 dracut/state-json/unmask, M11 prereq gate; 4 non-clean inverses) — this plan closes all six NOT-REVERSED rows and the non-clean ones it can do safely.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer (root) → /etc, units, grub | Privileged writes across system configuration |
| `--uninstall` in rescue shell → host | Privileged removal without build-tool/root preconditions |
| foreign drop-in dirs → installer | Shared systemd drop-in directories the installer must not wipe |
| `--verify --root DIR` → arbitrary tree | Manifest-driven read of a possibly operator-supplied root |
