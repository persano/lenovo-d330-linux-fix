# Milestone 6: System Resilience, Performance & Usability Polish (v6.0)

## Overview
Milestone 6 brings high-impact quality-of-life, hardware acceleration, fanless thermal mitigation, memory resilience, and desktop shell usability features to complete the Lenovo IdeaPad D330-10IGL Linux ecosystem.

## Phases

### [x] Phase 24: Intel VA-API Hardware Video Acceleration
- **Target**: UHD Graphics 600 (Gemini Lake GLK 12 EU) hardware decode offloading.
- **Components**:
  * `/etc/environment.d/50-lenovo-d330-vaapi.conf` (`LIBVA_DRIVER_NAME=iHD`, `MOZ_DISABLE_RDD_SANDBOX=1`).
  * `/etc/firefox/pref/d330-vaapi.js` (Hardware VAAPI decode prefs for Firefox).
  * `tools/d330-vaapi-check.sh` (Diagnostic & validation tool).
  * `scripts/test_vaapi.sh` (Test harness).
  * `docs/research/VAAPI_HARDWARE_ACCELERATION.md`.

### [x] Phase 25: Fanless Thermal Tuning & RAPL Power Limits
- **Target**: Fanless chassis thermal cliff mitigation (preventing drops to 800MHz floor).
- **Components**:
  * RAPL clamping: PL1 sustained 5.0W (down from 6.0W), PL2 burst 8.0W with 15s window.
  * `/etc/thermald/thermal-conf.xml` (thermald XML profile for GLK DPTF zones).
  * `tools/d330-thermal-tune.sh` (RAPL sysfs direct register clamp script).
  * `patches/thermal/etc/systemd/system/d330-thermal.service`.
  * `scripts/test_thermals.sh` (Thermal & RAPL verification harness).
  * `docs/research/FANLESS_THERMAL_RAPL.md`.

### [x] Phase 26: Out-Of-Memory Prevention (earlyoom)
- **Target**: Prevent 4GB RAM + ZRAM thrashing kernel OOM lockups.
- **Components**:
  * `/etc/default/earlyoom` (`-m 4 -s 10 --prefer '^(firefox|chromium|chrome|electron|slack|code)'`).
  * `/etc/systemd/system/earlyoom.service.d/d330-override.conf`.
  * `scripts/test_oom_protection.sh`.
  * `docs/research/OOM_PREVENTION.md`.

### [x] Phase 27: Tablet Mode OSK Auto-Summon & Long-Press Right-Click
- **Target**: Touch ergonomics in tablet mode and X11/Wayland shells.
- **Components**:
  * `patches/touchscreen/etc/X11/xorg.conf.d/50-touchscreen-d330.conf` (`EmulateThirdButton` 750ms).
  * `tools/d330-tablet-daemon.py` (KDE Plasma D-Bus & X11 Onboard auto-summon on detach/fold).
  * `scripts/test_tablet_osk.sh`.
  * `docs/research/TABLET_OSK_GESTURES.md`.

### [x] Phase 28: PipeWire RNNoise Neural AI Microphone Denoising
- **Target**: Suppress chassis noise, typing, and fanless coil buzz on internal ES8336 microphone.
- **Components**:
  * `/etc/pipewire/filter-chain.conf.d/51-lenovo-d330-rnnoise-mic.conf` (LADSPA RNNoise filter-chain).
  * `scripts/test_mic_rnnoise.sh`.
  * `docs/research/PIPEWIRE_RNNOISE_MIC.md`.

### [x] Phase 29: Wi-Fi & Bluetooth Coexistence & S2idle Sleep Stability
- **Target**: Realtek RTL8821CE single-antenna sharing contention and post-sleep drops.
- **Components**:
  * `/etc/modprobe.d/lenovo-d330-wireless.conf` (`ant_sel=2`, `bt_coex_active=1`, `disable_lps_deep=1`).
  * `/usr/lib/systemd/system-sleep/lenovo-d330-wifi-resume.sh` (Automated interface toggle on wake).
  * `scripts/test_wireless_coex.sh`.
  * `docs/research/WIFI_BT_COEXISTENCE.md`.

### [x] Phase 30: Fast Boot Optimization for eMMC Storage
- **Target**: Reduce cold boot duration on 64GB eMMC from ~28s to ~9s.
- **Components**:
  * `/etc/default/grub.d/52-lenovo-d330-fastboot.cfg` (`nowatchdog`, `tsc=reliable`, `split_lock_mitigate=0`).
  * `tools/d330-fastboot-tune.sh` (Masking `systemd-networkd-wait-online` and slow services).
  * `scripts/test_boot_speed.sh`.
  * `docs/research/EMMC_FASTBOOT_TUNING.md`.

### [x] Phase 31: Desktop GUI System Tray Hardware Applet
- **Target**: GTK3 status icon exposing D330 hardware states directly from panel.
- **Components**:
  * `tools/d330-tray.py` (Battery conservation, Fn-lock, touch mode, RAPL profile, screen refresh).
  * `/etc/xdg/autostart/d330-tray.desktop`.
  * `scripts/test_tray_applet.sh`.
  * `docs/research/DESKTOP_TRAY_APPLET.md`.
