# Plan 47-01 — Dump Instrument: Additive i915 Debugfs Snapshot Node + CI Build (Tracer)

## Artifacts this phase produces

- `patches/d330_dsi_dump.patch` — unified diff adding the `i915_dsi_regs` debugfs snapshot node
- New kernel source file (inside the patch): `drivers/gpu/drm/i915/display/intel_dsi_dump_debugfs.c`
- CI workflow change: apply step + grep-proof anchors for the dump patch
- CI run artifact: `linux-image-*-d330-fix_*.deb` / `linux-headers-*-d330-fix_*.deb` (dump kernel)
- dmesg marker `D330DSIREG` (single confirmation line per trigger)

## Objective

Build the instrument the whole phase depends on: a strictly-additive debugfs
snapshot node in a CI-built i915 that reads back the five locked display MMIO
ranges plus the full DSI port/transcoder block, once per manual echo trigger,
into a frozen kernel buffer (D-01, D-02). Purpose: this is the only tool that
can capture boot-vs-resume hardware register truth deterministically on both
arms; everything downstream (47-03 capture, 47-04 diff) consumes its output.

Output: `patches/d330_dsi_dump.patch` + updated `build-kernel.yml` + a green CI
run producing the deployable dump-kernel `.deb`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| root shell → debugfs write handler | untrusted bytes written to the node by any root-capable process |
| debugfs node → userspace readers | raw GPU MMIO values exposed via cat (info-leak surface if perms wrong) |
| repo patches → CI kernel build | a malicious/widened patch silently changes the measured system |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-47-01 | Information Disclosure | i915_dsi_regs node | high | mitigate | node mode 0600, created under debugfs root (0700 by default); no world access; scope limited to the locked display ranges — no arbitrary-offset reads possible (compile-time walk table) |
| T-47-02 | Tampering | dump patch vs measured system | high | mitigate | strictly-additive patch contract (new file + 2 lines); CI grep-proof anchors; 47-03 eyes-on gate discards the pair if the panel unexpectedly lights |
| T-47-03 | Denial of Service | DSI block reads with PLL off | medium | mitigate | bxt_dsi_pll_is_enabled() gate mirroring intel_dsi_get_hw_state(); skip-marker instead of reads; hang is recoverable by reboot per assumption A3 fallback |
| T-47-04 | Tampering (input) | debugfs write handler | medium | mitigate | kstrtobool-only trigger; no offset/length parameters accepted; mutex re-entry guard |
| T-47-05 | Repudiation | CI provenance of the instrument | low | accept | CI run ID + artifact sha256 recorded in plan summary; run log is the provenance record |
