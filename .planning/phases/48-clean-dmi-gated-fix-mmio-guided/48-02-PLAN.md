<threat_model>
- Surface: deploy script runs as root on the device. Threats: (a) flashing an unverified image (bricks boot), (b) silently deleting the rollback asset, (c) credential leakage in logs.
- Controls: script hard-fails unless both shas verify (new deb + rollback deb) before any dpkg -i; rollback asset is never removed by the script; sudo password passed via stdin echo (existing device convention), never written to any file or echoed in output; no curl|sh; deb sha256 compared against CI-announced hash via gh output.
- Severity: medium → mitigated as above. No high-severity threats. ASVS L1.
</threat_model>
