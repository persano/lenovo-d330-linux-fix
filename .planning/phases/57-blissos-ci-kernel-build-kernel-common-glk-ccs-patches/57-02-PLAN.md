## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workflow_dispatch input -> clone URL/branch | User-supplied `ref` crosses into a privileged runner step (fixed upstream org, arbitrary ref name) |
| fresh upstream tree -> build/artifact | The kernel tree is untrusted input to every later step; the gate is the admission control |
| job outcome -> published artifact | Only a fully green job may produce a downloadable kernel |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-57-03 | Tampering / Information Disclosure | Unpatched or partially patched kernel published as artifact | critical | mitigate | Gate step (both `--check`s + ordered applies + grep anchors) precedes every build step; `upload-artifact` runs only on prior success, so red gate = no artifact (BLIS-02, AUDIT-03); no force-apply flags anywhere |
