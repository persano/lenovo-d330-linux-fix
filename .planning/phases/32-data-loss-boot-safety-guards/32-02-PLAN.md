## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tool → `/etc/fstab` | An appended entry is consumed by systemd-fstab-generator at every future boot; a malformed or `nofail`-less line hangs the machine before login |
| Mount failure → boot state | The window between append and successful mount decides whether a reboot hits an emergency shell |
| Test env (`D330_FSTAB`) → tool file writes | The test seam redirects fstab writes; it must never reach the real file or weaken the format path |
