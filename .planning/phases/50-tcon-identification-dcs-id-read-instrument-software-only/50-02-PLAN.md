## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| capture script → debugfs node | root shell writes the trigger; the script must bound the trigger so a wedged kernel read cannot hang the session |
| device dumps → diff tooling | untrusted-format output files feed a parser; a format drift must fail loudly, not misclassify rows |
| sweep probes → live I2C buses | i2cdetect -y probes addresses on live adapters (incl. the PMIC bus) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-50-04 | Denial of Service | echo-2 trigger on a wedged link | medium | mitigate | `timeout 15` wrap on the trigger in both echo-2 arms; failure exits non-zero with stderr; kernel side is bounded too (50-01) — belt and braces per the locked decision |
| T-50-05 | Repudiation | diff format drift misclassifying evidence | medium | mitigate | DCS rows are a distinct parser kind; three selftest fixtures pin the classification; determinism fixture guards byte-stability |
| T-50-06 | Denial of Service | i2cdetect -y probing live adapters | low | mitigate | standard quick-write probes only (i2cdetect default), every probe `|| true`, one dead bus never aborts the sweep; the sweep runs once per arm, not in a loop |
| T-50-SC | Tampering | npm/pip/cargo installs | high | mitigate | no registry installs this phase; device-side i2c-tools/libgpiod-tools are canonical Ubuntu archive packages installed (if absent) in 50-04 with versions archived |
