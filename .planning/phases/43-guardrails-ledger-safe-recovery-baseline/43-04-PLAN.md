## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| kit artifacts → restore path | Golden i915.ko.zst restored onto the device must be byte-verified before any restore; a swapped artifact bricks the display driver |
| manifest → sha256sum -c | The manifest is the integrity anchor; format errors must fail verification, not pass |
| runbook → on-device execution | Documented steps execute on real hardware at deployment; the repo can only pin their content |
