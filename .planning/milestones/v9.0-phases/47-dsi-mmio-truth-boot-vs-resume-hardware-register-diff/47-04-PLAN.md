Turn the capture pair into the named mechanism (MMIO-02): run the 47-02 diff
tooling on the 47-03 dumps, reconcile every result against prior machine
evidence (the known 21-row cold-vs-resume table and the empty resume-vs-reload
diff), and write `DSI_MMIO_DIFF.md` ending in ONE testable mechanism claim plus
the register list Phase 48 will restore or replicate. Purpose: three v8.0
candidates failed because kernel-visible state was byte-identical; this
document is the first hardware-level map of what actually differs, and its
claim form is constrained so it cannot hand Phase 48 a disproven lever.

Output: registered diff artifact + the completed DSI_MMIO_DIFF.md with all
gates green.
