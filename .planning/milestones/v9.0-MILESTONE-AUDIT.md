## The corrected mechanism (the milestone's scientific result)

- Boot (image showing): the GOP leaves the DSI operational set **X=Y**
  (0x6b010=003fffff, 0x6b044=0000001d, 0x6b080/0x6b098=09051003,
  0x6b088=0022000f, 0x6b094=1, 0x160018=0x115).
- Every broken state (wake+1 s, late-black 30 s ×2 cycles, rebind): **X=Z held
  indefinitely** (0000b8ea / 0000001e / 0a051003 / 0014000c / 0 /
  0x6b004 timeout-marked 40280000). The X=Y/X=Z contrast discriminates
  working from broken.
- Every kernel path tested — 3 resume variants AND the full PCI re-probe —
  lands at X=Z; forcing X=Y values (v8.0 row 18) is insufficient. Only the
  GOP's firmware init reaches the working state (and does direct TCON
  programming the kernel cannot see — GOP_DSI_RE_FINDINGS; the DPHY
  0x162000+ area reads all-ones).
- Withdrawn: the phase-48 §5.1 "falsification" (its "working" arm was a
  black state — the reload leaves lit-black). Corrected: DSI_MMIO_DIFF §5.2,
  NO_CLEAN_FIX_PROOF §7.1, RESUME_VS_RELOAD_DIFFERENTIAL.
