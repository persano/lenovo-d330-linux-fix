# Plan 45-01 — RE Kit Acquisition + Binary RE + VBT Decode + Resume-vs-Reload Differential

## Goal

Acquire and hash-verify the RE inputs (Lenovo driver + BIOS capsule + on-device
SPI dump), decompile `igdkmd64.sys` and the GOP panel-init path with cited
evidence (Ghidra headless), decode the VBT's DSI link config, and run the
instrumented on-device differential proving what the reload does that resume
does not (ROOT-01) — the evidence base the fix plan (45-02) designs against.
